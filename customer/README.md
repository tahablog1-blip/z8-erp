# تطبيق العميل للحجز (Z8 Customer)

تطبيق Flutter أصلي للعميل يعمل على **أندرويد وآيفون** من كود واحد. يستخدم نفس المسارات العامة لصفحة الحجز على الموقع (`/api/cars/public/*` و `/api/service-notes/public/*`)، فلا يحتاج أي تعديل على الخادم.

## اللغات والهوية
- 5 لغات: العربية والإنجليزية والبنغالية والهندية والأردية (باكستان). تظهر شاشة اختيار اللغة أول تشغيل، وتُغيَّر من القائمة (⋮) داخل التطبيق. الأردية والعربية من اليمين، والباقي من اليسار.
- النصوص العربية في الكود هي المفاتيح: `tr('نص عربي {0}', [متغير])`. الترجمات في `tools/translations_data.py` ثم `python3 tools/gen_translations.py` يولّد `lib/core/translations.dart` ويفحص التغطية. **راجِع الترجمات البنغالية والهندية والأردية مع متحدث أصلي قبل النشر.**
- شاشة الافتتاح: صورة الفرع بتدرّج أزرق شفاف، والشعار يُرسم بخط واحد متصل يبدأ من أعلى يسار الـ Z ثم الثمانية حتى يكتمل، وبعده تعبر عليه لمعة معدنية متحركة (يتخطاها اللمس). الصورة `assets/images/branch-bg.jpg` والشعار `logo-white.png`.
- خطوط Noto (بنغالي/ديفاناجري/نسخ) مضمّنة لعرض البنغالية والهندية وحروف الأردية.

## ما يفعله
- أول فتح: قائمة بكل الفروع (خدمة / بيع تجزئة) تظهر فوراً دون إدخال أي رابط، ثم تُرتَّب بالأقرب للعميل مع المسافة ووقت الوصول التقريبي بالسيارة وزر الاتجاهات. فرع التجزئة للعرض والاتجاهات فقط (لا حجز دور).
- وقت الوصول تقدير تقريبي: الخط المستقيم × 1.3 بسرعة 30 كم/س داخل المدينة و50 كم/س للأبعد، ولا يعتمد على الازدحام الفعلي.
- الفروع بلا إحداثيات تظهر آخر القائمة؛ تُدخَل من الموقع: الفروع ← تعديل ← موقع الفرع على الخريطة.
- يتذكر التطبيق الفرع المختار، ويمكن تغييره من القائمة.
- تأكيد الجوال برمز OTP (إن كانت الشركة فعّلته) واسترجاع السيارات المحفوظة.
- حجز بسيارة محفوظة بضغطة، أو بسيارة جديدة (لوحة، ماركة وموديل من قوائم الفرع، سنة، عداد، وقود).
- زيت خارجي (العميل يحضر زيته): الأجرة فقط وتصل الموظف ملاحظة. والمنتج النافد يُكتب عليه «غير متوفر الآن» ولا يُختار.
- اختيار الخدمات (يمكن الجمع): تغيير زيت ماكينة / جير / دفرنس / دبل، ولكل خدمة زيت مفلتر بنوعه (من تصنيف الأصناف في الموقع) وكمية باللتر، مع فلتر الزيت المطابق وأجرة خدمة زيت الماكينة تلقائياً (الجير والدفرنس والدبل تُحدَّد أجرتها داخل الفرع)، والإجمالي قبل التأكيد. الزيوت المصنّفة «زيت دبل» تُضبط من شاشة الصنف في الموقع، وغير المصنّف يظهر بكل الزيوت.
- صفحة لكل سيارة: بياناتها، حجز خدمة لها، وسجل تغييراتها (فواتير هذه السيارة فقط)، وقسم «فواتيري» لكل فواتير العميل مع أصنافها وPDF.
- نوع الوقود: ديزل / بنزين / هايبرد فقط. تسجيل السيارة الجديدة: الماركة ثم الموديل (قائمة قابلة للتعديل بالكتابة)، والسنة وحجم الماكينة من قوائم، وعدد السلندرات. الكمية بالقطعة (أعداد صحيحة).
- تذكرة الدور الحيّة: رقم الدور، عدد السيارات قبلك، الوقت المتوقع، والحالة (تتحدث كل 10 ثوان).
- محادثة نصية مع الفرع + ملاحظات الخدمة المرئية للعميل.

لم يُبنَ بعد: أنواع الحجز "تحت الضمان" و"فاتورة شركة"، الرسائل الصوتية، الإشعارات الفورية (Push).

## التحديث بدون تنزيل الملفات كل مرة
بدل تنزيل ZIP في كل تحديث، استنسخ المشروع **مرة واحدة** بـ git ثم حدّثه بأمر:
1. **مرة واحدة:** في Android Studio: File ← New ← Project from Version Control ← الصق `https://github.com/tahablog1-blip/z8-erp.git` ← سجّل الدخول بحساب GitHub عند الطلب ← Clone. (أو GitHub Desktop: File ← Clone repository.) ثم افتح مجلد `customer` من داخل النسخة.
2. **عند كل تحديث:** في Android Studio اضغط VCS ← **Update Project** (أو Ctrl+T) واختر Merge، ثم من الطرفية داخل `customer`: `flutter pub get`. أو شغّل `powershell -ExecutionPolicy Bypass -File update.ps1` فيفعل الخطوتين.
3. أوقف التطبيق وشغّله من جديد (وليس Hot restart).

لا تعدّل ملفات المشروع في نسختك المحلية كي لا تتعارض عند التحديث.

## التشغيل من Android Studio
1. افتح المجلد `customer` (وليس جذر المشروع) في Android Studio.
2. `flutter pub get` ثم شغّل على المحاكي أو جهاز حقيقي.
3. اختياري: تثبيت فرع واحد وقت البناء (يتخطى قائمة الفروع):
   ```
   flutter run --dart-define=BRANCH_ID=<معرّف-الفرع> --dart-define=API_BASE=https://z8masdr.duckdns.org
   ```
   معرّف الفرع هو الجزء الأخير من رابط الحجز `https://…/booking/<معرّف-الفرع>`.

## الآيفون
البناء لآيفون يتطلب جهاز Mac وXcode وحساب Apple Developer:
```
cd customer && flutter build ios --dart-define=BRANCH_ID=…
```
غيّر `com.z8masdr.z8_customer` (Bundle Identifier) إلى معرّفك من Xcode (Runner ثم Signing & Capabilities).
