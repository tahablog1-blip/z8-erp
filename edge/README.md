# وكيل المحطة (Z8 Camera Agent)

## لماذا؟
السيرفر في السحابة ولا يستطيع الوصول إلى كاميرات عناوينها داخلية (`192.168.x.x`) — وهذا سبب `ConnectTimeout` في سجله.
الوكيل برنامج صغير على كمبيوتر **داخل شبكة المحطة** (موصول بنفس الراوتر/السويتش مع الكاميرات):
يقرأها محلياً ويتصل بالسيرفر **اتصالاً خارجياً فقط** (HTTPS). لا IP عالمي، لا فتح منافذ، يعمل خلف أي إنترنت (حتى شبكة جوال).

## ما يفعله
1. **نبضة حياة** كل 15 ث ويجلب كاميرات فرعه من الموقع (لا ملفات إعداد للكاميرات) ويُبلغ حالة كل كاميرا (تظهر في الموقع).
2. **مراقبة حركة كاميرات المدخل** (المحطة 1): عند دخول سيارة يرسل اللقطة لقراءة اللوحة وتسجيل الدخول تلقائياً.
3. **لقطة عند الطلب**: اختبار الكاميرا من الموقع، لقطة المحطة، فحص السيارة، المشرف الآلي — كلها تمر عبر الوكيل تلقائياً.
عند اتصال الوكيل يتوقف السيرفر عن محاولة الوصول المباشر لكاميرات ذلك الفرع. وإن انقطع الوكيل يعود السيرفر للسلوك القديم.

## تركيبة محطتك (مثال)
سيران، لكل سير كاميرا مدخل ← كاميرتان في **المحطة 1** · ثلاث حفر، لكل حفرة كاميرا ← ثلاث كاميرات في **المحطة 2**.
أضف الكاميرات من الموقع (الإعدادات ← كاميرات المحطات) بعناوينها الداخلية، ثم أنشئ الوكيل. وكيل واحد يخدم المحطة كلها.

## التثبيت
1. من الموقع: **الإعدادات ← كاميرات المحطات ← وكلاء المحطات** ← اختر الفرع واكتب اسماً ← **إنشاء وكيل** ← انسخ المفتاح (يظهر مرة واحدة).
2. على كمبيوتر المحطة (يبقى يعمل دائماً ومتصلاً بنفس شبكة الكاميرات):
   - **ويندوز:** ثبّت Python 3.10+ (مع Add to PATH)، انسخ مجلد `edge`، وشغّل PowerShell كمسؤول:
     `powershell -ExecutionPolicy Bypass -File install-windows.ps1` (يفتح agent.env: ضع المفتاح، ثم أعد التشغيل). يبدأ تلقائياً مع كل إقلاع.
   - **لينكس / Raspberry Pi:** `python3 -m venv venv && venv/bin/pip install -r requirements.txt`، ضع `agent.env`، ثم ثبّت `z8-agent.service`.
3. افتح الموقع: يجب أن يظهر الوكيل **متصلاً** وكاميراته خضراء. اضغط «اختبار» على أي كاميرا لتتأكد أن اللقطة تصل.

## متطلبات الكاميرات
- Hikvision: يُجرَّب ISAPI (`/ISAPI/Streaming/channels/101/picture`) أولاً (أسرع وأنظف) ثم بث RTSP. الرابط بالصيغة `rtsp://user:pass@IP:554/...`.
- كاميرا HTTP (مثل تطبيق كاميرا الجوال): رابط `http://...` للقطة.

## الأمان
- المفتاح خاص بفرع واحد: يرفض السيرفر استعماله لفرع آخر، ويُلغى فوراً من الموقع.
- الكاميرات تبقى بعناوين خاصة ولا تُعرَّض للإنترنت إطلاقاً.
- لا يخزّن الوكيل كلمات مرور الكاميرات في ملفاته؛ تأتيه من الموقع عند كل نبضة.
